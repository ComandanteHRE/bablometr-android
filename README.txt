БАБЛОМЕТР ДЛЯ ANDROID
=====================

Это Android-приложение, которое показывает на весь экран страницу app\src\main\assets\index.html.
Те же поля и расчёты, что в настольной версии. Данные хранятся на телефоне, в самом приложении.

!!! Сборку APK я проверить не мог (у меня нет доступа к Android SDK). Саму страницу я проверил в браузере.
    Если сборка выдаст ошибку, пришлите её текст.

Как получить APK. Три способа (самый простой — первый)
-----------------------------------------------------
1) Через GitHub: ничего не надо ставить на компьютер
   a. Зарегистрируйтесь на github.com (бесплатно) и создайте новый репозиторий (New repository).
   b. Нажмите «uploading an existing file» и перетащите в окно ВСЁ содержимое этой папки
      вместе с подпапками, включая скрытую папку .github (если её не видно, в проводнике включите
      «Показывать скрытые элементы»). Нажмите Commit changes.
   c. Откройте вкладку Actions -> «Build APK» -> Run workflow. Через 3–5 минут сборка закончится.
   d. Откройте завершённый запуск, внизу в разделе Artifacts скачайте «Bablometr-apk»,
      распакуйте архив. Внутри файл app-debug.apk.

2) Через Android Studio (бесплатная, developer.android.com/studio)
   File -> Open -> выберите эту папку. Дождитесь окончания синхронизации (скачает всё нужное).
   Меню Build -> Build App Bundle(s) / APK(s) -> Build APK(s). Готовый файл:
   app\build\outputs\apk\debug\app-debug.apk

3) Без APK: откройте страницу bablometr.html в Chrome на телефоне и выберите
   меню ⋮ -> «Добавить на главный экран». Работает так же, данные хранятся в браузере.

Как установить APK на телефон
-----------------------------
1. Скопируйте app-debug.apk на телефон (по USB, через облако или мессенджер).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника —
   разрешите (Настройки -> «Установка неизвестных приложений»).
3. Нажмите «Установить». Значок «Bablometr» появится в списке приложений.
Это отладочная сборка, подписанная тестовым ключом: для личного использования подходит,
в Google Play в таком виде выкладывать нельзя.

Как пользоваться
----------------
* Под шкалой одна строка полей: Start, End, $/day, +Bonus$. Значения сохраняются сами.
* Маленькие кнопки с красной рамкой рядом с Start и End переключают поле между датой и временем.
* Молоток в правом верхнем углу показывает и прячет нижнюю строку.
* Start не может быть позже текущего момента и позже End.
* После даты End заработок и шкала больше не растут.
* Если вы пользовались предыдущей версией со списком людей, подтянутся данные того, кто был выбран последним.
